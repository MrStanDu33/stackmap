# 4. License pending, contributions under a CLA

- Status: accepted
- Date: 2026-10-10

## Context

Stackmap may become a commercial product (paid support, a cloud offer). The license is not chosen yet: AGPL with a
commercial directory, a fair-code license, or a permissive core are all possible. The repository is public.

## Decision

- Until a license is chosen, `LICENSE` reserves all rights.
- Contributions are accepted under an individual **Contributor License Agreement** (`docs/CLA.md`), signed through
  CLA Assistant Lite on the first pull request. It allows the project to be licensed, and relicensed, later.
- Choosing the license is priority 0 of the roadmap, before the first release.

## Consequences

- Outside contributors must sign the CLA; some may decline. A Developer Certificate of Origin would be lighter but does
  not allow relicensing.
- The CLA text is a draft adapted from the Apache Individual CLA and should be reviewed by a lawyer.
